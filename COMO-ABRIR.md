# Clone do recargajogo.com.br

Cópia offline do site. Só precisa do **Node.js 18+** instalado (nada de instalar pacote).

## Abrir

Dentro desta pasta, rode:

```
node servir.cjs recargajogo 4700
```

Depois abra no navegador: **http://localhost:4700/**

Para parar: `Ctrl+C`.

## Páginas capturadas

- Home
- Free Fire, Delta Force, HAIKYU!! FLY HIGH, Monster Hunter Outlanders
- Evento
- FAQ

## Observações

- É uma cópia estática: login, troca de servidor, pagamento e contadores ao vivo não funcionam.
- Mudar a porta: troque `4700` por outro número no comando.
